Bring your saved work with you.

Favorites, boards, saved projects and AI images stay in the browser where you created them. A new website address cannot read the old address’s private browser storage.

First open this page on UltraClipart in the same browser and profile you used before. Save a private backup. Then open this page on JotClipart and choose that file. Nothing is sent to a server, and nothing is deleted from either site.

This page is currently using . Only click the buttons when you are ready. A backup is not encrypted: keep it somewhere private.

What to include

Favorites and boards, notes, saved editor projects, checkpoints, element favorites and design preferences are included.

Cookies, sign-in sessions, temporary AI handoffs and unrelated browser data are excluded. A backup is limited to 128 MB of source data and 192 MB as a JSON file. If a large project exceeds the limit, export that project separately from Studio; the tool will stop rather than silently omit records.

1. Save on the old address

Use the original browser and profile. The file includes only the saved-work locations listed here, with file and binary checksums.

2. Restore on JotClipart

Choose the saved file. Newer work is kept. Conflicting versions are retained separately instead of overwriting either copy.

After restoring, check your Favorites and Studio projects before discarding a backup. If a transfer stops, keep the file and retry: identical records are deduplicated. The site cannot recover another browser profile’s data or an earlier deleted browser history.

Exactly which storage is included?

Only UltraClipart favorites/boards/view preferences, element favorites, the palette, workbench preferences, editor recovery and checkpoint keys; the known Studio projects and AI image-history databases. This is not a dump of all storage. Public-link removal keys require the optional checkbox above.

The destination keeps its current copy on conflicts. Incoming conflicting or unsupported versions are saved in a separate local transfer archive and can be downloaded with the button above. No existing record is cleared or replaced blindly.
